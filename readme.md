# 📍 Vizag Local Guide: The City of Destiny
An AI-powered local guide built for the **AI for Bharat Week 5 Challenge**. This tool uses custom local context to provide "street-smart" advice for Visakhapatnam.

## ✨ Features
- **Local Nuances**: Understands Vizag-specific slang like "Mowa."
- **Hidden Gems**: Recommends authentic street food spots (e.g., MVP Colony Punugulu).
- **Traffic Hacks**: Provides navigation shortcuts for busy junctions like Siripuram.
- **Context-Aware**: Powered by a custom `product.md` file.

## 🛠️ Tech Stack
- **Language**: Python
- **Frontend**: Streamlit
- **AI Model**: Gemini 1.5 Flash (via Google Generative AI)
- **Agentic IDE**: Kiro

## 🚀 Quick Start
1. **Clone the repo**:
   `git clone <your-repo-link>`
2. **Install dependencies**:
   `pip install -r requirements.txt`
3. **Run the app**:
   `streamlit run app.py`

## 🔧 Project Structure
- `.kiro/`: Directory containing Kiro configuration.
- `product.md`: The mandatory context file containing local Vizag nuances.
- `app.py`: Main application logic.
- `requirements.txt`: Project dependencies.
